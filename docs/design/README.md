# CareConnect wireframes (P4)

These low-fidelity SVG wireframes are based on the current screens and terminology in `web/src/App.jsx` and the P4 CareConnect requirements in Assignment 2. Open any SVG in a browser, Figma, Inkscape, or VS Code.

1. `wireframe-01-patients.svg` — patient browsing, search, HSA balance and details
2. `wireframe-02-clinics.svg` — clinic browsing, search, accepting-patients status and details
3. `wireframe-03-appointments.svg` — appointment list, search, details and status updates
4. `wireframe-04-book-appointment.svg` — transaction workflow, HSA before/after, success/error and audit entry
5. `wireframe-05-audit-trail.svg` — patient/date filters and wallet audit records
6. `wireframe-06-analytics.svg` — clinic revenue, 7-day average, ranked clinics and materialized-view refresh
7. `wireframe-07-reviews-medical-catalog.svg` — rating distribution, review tags, average rating and medical catalog
8. `wireframe-08-nearby-nurses-map.svg` — selectable origin, 5 km radius, nurse map and distance-sorted list

The rows and values shown are illustrative placeholders for wireframe layout, not claims about the live database. Replace them with seeded data during implementation.
